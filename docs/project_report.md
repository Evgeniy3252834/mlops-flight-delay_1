# Отчет по проекту MLOps Flight Delay Prediction

## 1. Введение

### Цель проекта
Разработка end-to-end MLOps пайплайна для предсказания задержек авиарейсов.

### Задачи
- Версионирование данных (DVC)
- Эксперименты и регистрация моделей (MLflow)
- Feature Store (Feast)
- REST API (FastAPI)
- Оркестрация пайплайнов (Airflow)
- Контейнеризация и оркестрация (Docker, Kubernetes)
- Мониторинг (Prometheus, Grafana)
- Детекция дрейфа
- CI/CD (GitHub Actions)

## 3. Реализация

### 3.1 Версионирование данных (DVC)
- Данные в `data/raw/`
- DVC пайплайн в `dvc.yaml`
- Локальный remote

### 3.2 Эксперименты (MLflow)
- Логирование параметров и метрик
- Model Registry с версионированием

### 3.3 Feature Store (Feast)
- Сущности: carrier, airport, hour
- Feature views для статистик

### 3.4 API (FastAPI)
- Endpoint `/predict`
- Endpoint `/health`
- Endpoint `/metrics`

### 3.5 Оркестрация (Airflow)
- DAG для полного пайплайна

### 3.6 Мониторинг (Prometheus + Grafana)
- HTTP request counter
- Request latency histogram
- Дашборд в Grafana

### 3.7 Детекция дрейфа
- PSI для признаков
- Автоматическое переобучение

### 3.8 CI/CD (GitHub Actions)
- Тесты при каждом push
- Сборка Docker образа
- Деплой в Kubernetes

## 4. Метрики модели
- **Accuracy**: 0.95
- **ROC-AUC**: 0.98
- **Precision**: 0.94
- **Recall**: 0.96

## 5. Заключение
Проект успешно реализует полный MLOps цикл. Все компоненты интегрированы в единую систему.
